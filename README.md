# SmartInsure — Insurance Management Application

## Overview
SmartInsure is a collaborative academic project focused on insurance management, developed as part of the ESPRIT engineering curriculum.

## Technologies
- **Backend:** Java, Spring Boot
- **Frontend:** Angular
- **Database:** MySQL

## Project Scope
The application covers insurance-related workflows, including contract management, invoices and customer claims.

## My Contribution
I contributed to backend development, particularly the implementation and evolution of invoice and claim management features, as well as contract-related functionality.

## Source Code
The complete source code is maintained in a separate private repository belonging to the project team. This public repository serves as a project presentation and does not contain the team's source code.
